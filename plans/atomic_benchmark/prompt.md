### Summary

I want to see how many moves per second can be generated with this
application.
So we need to extend/rewrite Fairy-Stockfish such that it can be used to give a 
benchmark on the moves per seconds generated by the move generator.

### Ideas

- when the application is started with a new flag `movegen_bench` it runs the benchmark
  - e.g. `./stockfish movegen_bench atomic` runs the benchmark for the atomic variant
- the benchmark runs for 10 seconds and shows a summary in the end
- for now only one core is used for the benchmark, no parallelization
- to simulate a variation of positions use a very simple minimax/negamax search
  - don't add any optimizations to the search like move ordering etc. as this impacts performance
  - don't evaluate postion scores as this is impacts performance
